# Архив дизайна ФотоПорядка

Сюда сохраняются утверждённые макеты, варианты кнопок, значки, обои тем и другие визуальные материалы.

## Правила
- Сохранять исходный файл макета, а не только описание.
- Имена файлов должны отражать версию/дату и вариант, например `ui-concept-v2-approved.png`.
- Рядом добавлять короткое описание: что именно пользователь утвердил, какие детали обязательны, что отклонено.
- Не заменять утверждённый макет новым вариантом без согласования.
