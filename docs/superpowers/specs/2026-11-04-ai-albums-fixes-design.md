# Исправления ИИ-альбомов и возврата — дизайн

Дата: 2026-11-04  
Проект: ФотоПорядок 2.6

## Цель
Исправить наблюдаемые проблемы версии 2.5: исчезновение результатов ИИ после смены вкладки, некорректные обложки, технические подписи фотографий, ложные категории и недостаточно понятный индикатор обновления.

## Согласованные требования
- Сохранённые результаты анализа должны восстанавливаться из локального SQLite-кэша при повторном открытии ИИ-альбомов.
- Возврат к экрану ИИ не должен требовать повторного анализа.
- Обложка альбома — компактный коллаж из нескольких фотографий с Crop, без пустых полос.
- Внутри альбомов/категорий показываются фотографии без категорий и сырых ML Kit labels.
- Категория «Животные» не назначается по одной слабой/случайной метке; сомнительные результаты остаются нейтральными.
- На кнопке обновления явно написано «Доступно новое обновление», рядом отображается номер версии; зелёный акцент сохраняется.
- Внутренний системный Back должен возвращать на предыдущий экран, а не закрывать приложение при переходе между вкладками.

## Реализационные решения
- SQLite остаётся источником сохранённых меток; при создании экрана читаются только уже закэшированные результаты.
- Порог уверенности ML Kit поднят до 0.62; для категории животных требуются как минимум две различные предметные метки.
- Заголовок альбома строится из итоговой категории, а не из случайной одиночной ML-метки.
- Обложка формируется из первых четырёх элементов альбома в сетке 2×2.
- Для внутренних экранов и страницы ИИ добавляется обработка BackHandler.
- Аварийное закрытие NullPointerException не объявляется исправленным без stack trace; после получения лога нужна отдельная диагностика.

## Проверка
- GitHub Actions: assembleDebug и assembleRelease.
- Проверить повторный вход на вкладку ИИ после анализа, коллажи 1–4 фото, отсутствие ML-подписей, нейтральную классификацию одиночного Dog, переход Back с ИИ на главную.
- На Poco F8 Ultra отдельно проверить реальный системный жест Back и собрать stack trace при повторном NullPointerException.
