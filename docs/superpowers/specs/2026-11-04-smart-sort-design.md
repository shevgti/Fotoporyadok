# Умная сортировка — дизайн

Дата: 2026-11-04
Проект: ФотоПорядок (Android, Kotlin, Jetpack Compose)

## Цель
Добавить второй экран «Умная сортировка», где приложение предлагает разложить локальные фото и видео по папкам, позволяет просмотреть содержимое и переименовать папки, а перемещение выполняется только после явного подтверждения пользователя.

## Согласованные требования пользователя
- Внизу приложения две вкладки: «Главная» и «Умная сортировка».
- На экране сортировки есть запуск анализа медиатеки.
- Предварительный результат показан папками; можно открыть папку, посмотреть элементы и изменить название.
- Отдельная кнопка подтверждения запускает фактическое распределение в медиатеке Android.
- До подтверждения файлы не перемещать и не менять.
- Существующий экран, его стиль, поиск, фильтры, обновление и обновление APK сохранить.

## Предлагаемое поведение (технические решения реализации)
- Не заявлять распознавание содержания фото: без отдельной ML-модели приложение не знает, что изображено. Первый безопасный вариант использует метаданные MediaStore.
- Группировать по дате съёмки/добавления, с учётом существующего альбома; названия папок формировать понятными датами и исходным альбомом. Папки предварительного просмотра редактируемы.
- В превью показывать количество фото и видео, миниатюры и полный список элементов выбранной папки.
- Использовать относительный путь в MediaStore, чтобы перемещать существующие элементы, а не создавать дубликаты.
- На Android 11+ запрашивать системное подтверждение записи через MediaStore.createWriteRequest; на Android 10 обрабатывать RecoverableSecurityException; на Android 8–9 запрашивать разрешение записи в хранилище. Если система не разрешает безопасно завершить операцию, показать ошибку и не удалять/не терять оригиналы.
- Сортировка является предварительным планом до системного разрешения и пользовательского подтверждения.

## Не входит в первую версию
- Автоматическое распознавание лиц, мест, объектов и семантических событий.
- Удаление файлов, изменение изображений или загрузка в облако.
- Перемещение без явного действия пользователя.

## Подходы
1. Сортировать только по календарным датам: просто и предсказуемо, но игнорирует существующие альбомы.
2. Дата + исходный альбом (выбранный вариант): сохраняет контекст существующих папок, не делает неподтверждённых выводов о содержимом.
3. ML-распознавание событий: потенциально умнее, но требует модели, дополнительных ресурсов и отдельной проверки приватности; не подходит для первой версии.

## Критерии готовности
- Нижняя навигация открывает обе страницы.
- Анализ создаёт воспроизводимый план без перемещения файлов.
- Можно открыть папку и переименовать её.
- Подтверждение перемещает существующие элементы в выбранные папки через MediaStore с системными разрешениями.
- Существующий функционал остаётся доступен.
- CI сборка проходит; результаты проверок записываются честно.
