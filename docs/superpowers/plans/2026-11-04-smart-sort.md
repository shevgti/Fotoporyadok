# План реализации: Умная сортировка

## Шаг 1 — Модель и алгоритм
- Добавить модели группы сортировки и функции построения плана из MediaItem.
- Сначала написать unit-тесты для группировки: одинаковая дата/альбом вместе; разные даты/альбомы раздельно; пустой альбом имеет безопасное имя; переименование не меняет состав.
- Проверить RED, затем реализацию и GREEN.

## Шаг 2 — Навигация и экран предпросмотра
- Добавить нижние вкладки «Главная» / «Умная сортировка».
- На странице сортировки добавить запуск анализа, список папок, количество файлов, просмотр содержимого и редактирование имени папки.
- До подтверждения не выполнять операции записи.

## Шаг 3 — Перемещение через MediaStore
- Реализовать перенос существующих URI в Pictures/ФотоПорядок/<имя папки>.
- Android 11+: системное подтверждение MediaStore.createWriteRequest.
- Android 10: RecoverableSecurityException с запуском user consent.
- Android 8–9: WRITE_EXTERNAL_STORAGE permission.
- Частичные ошибки отображать отдельно; не удалять оригиналы и не сообщать об успехе для неудачных файлов.

## Шаг 4 — Проверка и память
- Запустить тесты и GitHub Actions assembleDebug/assembleRelease.
- Проверить сохранность существующего экрана и updater.
- Обновить README: реализация, ограничения, проверенные сценарии и точка продолжения.
- Не менять номер релиза до проверки и отдельного решения о публикации.
