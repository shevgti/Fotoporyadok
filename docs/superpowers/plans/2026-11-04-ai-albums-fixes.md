# План реализации: ФотоПорядок 2.6 — исправления ИИ-альбомов

- Не запускать ML Kit повторно, если пользователь только вернулся на вкладку.

## Шаг 2 — Визуальная часть и классификация
- Сделать обложку альбома сеткой 2×2 с Crop.
- Удалить категории и сырые распознанные метки из строк фотографий.
- Поднять порог уверенности и требовать несколько независимых animal labels для категории «Животные».
- Название альбома строить по категории, не по одиночной метке.

## Шаг 3 — Навигация и обновление
- Добавить обработку системного Back для бокового меню, полноэкранного просмотра и вкладки ИИ.
- Увеличить зелёный индикатор обновления и добавить явную надпись с номером версии.

## Шаг 4 — Проверка
- Запустить GitHub Actions buildDebug/buildRelease.
- Не считать NullPointerException исправленным без stack trace.
