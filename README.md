# ФотоПорядок

Android-приложение для просмотра и упорядочивания фотографий и видео на телефоне.

## Возможности
- ИИ-анализ фотографий на устройстве с помощью встроенной модели Google ML Kit Image Labeling; фотографии не отправляются на сервер.
- Умные альбомы по съёмочным сериям: названия формируются по распознанным объектам и сюжетам; группы из одной-двух фотографий не превращаются в альбомы.
- Результаты распознавания кэшируются локально в SQLite, повторный анализ использует кэш и обрабатывает новые/изменённые фотографии.
- ИИ-альбомы являются виртуальными подборками: оригиналы не перемещаются, не переименовываются и не удаляются.
- Просмотр локальной медиатеки Android.
- Разделы фото и видео, сортировка по дате.
- Компактная шапка галереи; медиатека автоматически перечитывается при изменениях в MediaStore.
- Полноэкранный просмотр фото и видео с переключением вертикальной/горизонтальной ориентации видеоплеера.
- Распознанные фотографии доступны также через виртуальные категории с количеством снимков; это фильтры, а не новые папки на телефоне.
- Десять тем оформления с фотографическими фонами и встроенная проверка обновлений APK.
- Десять фотографий тем с PxHere (CC0/Public Domain) скачиваются при сборке APK и включаются в локальные ресурсы; переключение тем и фон главного экрана работают офлайн.
- Проверка обновлений выполняется при открытии приложения и дополнительно через WorkManager в фоне (период 12 часов; фактическое время зависит от Android/HyperOS и энергосбережения). Для системных уведомлений требуется разрешение Android.

## Приватность
Приложение работает с локальной медиатекой Android. Оно не загружает личные фото и видео на сервер и не должно перемещать или изменять файлы без явного подтверждения пользователя.

## Сборка
Откройте проект в Android Studio или выполните:

```bash
gradle :app:assembleDebug
```

GitHub Actions собирает APK при push в основную ветку. Подписанные релизы публикуются в GitHub Releases.
