# ФотоПорядок

Android-приложение для просмотра и упорядочивания фотографий на телефоне.

## Что уже работает
- Читает доступные фотографии из локальной медиатеки Android.
- Показывает фотографии удобной сеткой с миниатюрами.
- Сортирует по дате съёмки (если она есть в файле), иначе по дате добавления.
- Позволяет менять порядок: сначала новые, сначала старые или по имени.
- Ищет фотографии по имени файла.
- Открывает увеличенный просмотр выбранной фотографии.
- Обновляет список по кнопке.

## Приватность
Приложение не загружает фотографии в интернет, не удаляет и не изменяет оригиналы. Доступ к фотографиям запрашивается у Android; на новых версиях системы можно разрешить доступ только к выбранным изображениям.

## Сборка APK
Откройте проект в Android Studio или запустите:

```bash
gradle :app:assembleDebug
```

GitHub Actions автоматически собирает debug APK при push в main. Готовый APK находится в артефактах успешного запуска сборки.
