# ФотоПорядок

Android-приложение для просмотра и упорядочивания фото и видео на телефоне.

## Что уже реализовано
- Читает доступные фотографии и видеозаписи из локальной медиатеки Android.
- Разделы «Всё», «Фото» и «Видео», а также счётчики файлов.
- Сетка миниатюр для фотографий и отдельные карточки видеозаписей.
- Сортировка по дате съёмки (если она есть), иначе по дате добавления; также сортировка по имени.
- Поиск по названию файла.
- Увеличенный просмотр фотографии.
- Открытие видео во внешнем видеоплеере.
- Ручное обновление списка.

## Приватность
Приложение не загружает медиафайлы в интернет, не удаляет и не изменяет оригиналы. Доступ запрашивает Android; на новых версиях системы можно разрешить доступ только к выбранным изображениям.

## Сборка APK
Откройте проект в Android Studio или запустите:

```bash
gradle :app:assembleDebug
```

GitHub Actions автоматически собирает debug APK при push в main. Готовый APK находится в артефактах успешного запуска сборки.

## Работа: «Умная сортировка» (2026-11-04)

Статус: функция включена в `main`; GitHub Actions run `41720418389` завершился успешно. Опубликован релиз `v0.5` (versionCode 5), APK доступен через встроенную кнопку «Обновить». На реальном телефоне ещё не проверено.

### Что добавлено в рабочую ветку
- Нижняя навигация «Главная» / «Умная сортировка».
- Построение предварительного плана по дате съёмки (если доступна, иначе дата добавления) и исходному альбому.
- Карточки папок с количеством файлов, переименование папок и просмотр содержимого в сетке миниатюр (фото) и значков видео.
- Перед переносом требуется отдельное нажатие «Подтвердить распределение».
- На Android 11+ перед изменением MediaStore запрашивается системное разрешение через `MediaStore.createWriteRequest`.
- Файлы не копируются и не удаляются: меняется относительный путь существующих записей MediaStore.

### Ограничения первой реализации
- Это сортировка по метаданным, а не распознавание того, что изображено на фото. Названия «событий» автоматически не угадываются.
- Фото перемещаются в `Pictures/ФотоПорядок/`, видео — в `Movies/ФотоПорядок/`.
- В текущей версии фактический перенос включён только для Android 11+; на Android 10 и ниже экран сообщает об ограничении и не трогает файлы.
- Просмотр папки показывает миниатюры фотографий, значки видео, имена и даты.
- Нужно проверить сценарии с большой медиатекой: системный запрос разрешения может потребовать пакетной обработки URI.

## Полноэкранный просмотр фото и видео + новый знак в шапке — 2026-11-04

Статус: согласовано пользователем; запланировано к реализации.

### Полноэкранный просмотр
- Нажатие на фото или видео в медиатеке открывает встроенный просмотрщик на весь экран, не внешний просмотрщик/плеер.
- Фото показываются крупно с сохранением пропорций; можно перелистывать соседние элементы медиатеки свайпом влево/вправо.
- Видео воспроизводятся внутри того же просмотрщика со стандартными элементами управления (пауза/воспроизведение, перемотка, звук при наличии).
- Переходы должны идти по текущему видимому списку с учётом выбранной вкладки, поиска, сортировки и альбома.
- Закрытие возвращает пользователя на прежнее место в сетке; не изменяет и не загружает оригиналы.

### Новый знак в шапке
- Использовать сгенерированную иллюстрацию ФотоПорядка (фото + видеохлопушка/кнопка воспроизведения) как маленький чёткий значок рядом с названием в верхней шапке.
- Слева от текста «ФотоПорядок» добавить маленький синий круглый индикатор.
- Удалить старый декоративный символ в фиолетовом квадрате, не меняя остальную компоновку шапки.

### Что нельзя менять

### Техническое решение
- Встроенный полноэкранный Compose-диалог/поверхность с просмотром текущего видимого списка.
- Для видео использовать AndroidX Media3 ExoPlayer и PlayerView с корректным освобождением плеера при закрытии/смене элемента.
