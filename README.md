# ФотоПорядок

Android-приложение для просмотра и упорядочивания фотографий и видео на телефоне.

## Возможности
- Просмотр локальной медиатеки Android.
- Разделы фото и видео, поиск и сортировка.
- Альбомы и полноэкранный просмотр фото и видео.
- Умная сортировка с предварительным планом и подтверждением пользователя.
- Темы оформления и встроенная проверка обновлений APK.

## Приватность
Приложение работает с локальной медиатекой Android. Оно не загружает личные фото и видео на сервер и не должно перемещать или изменять файлы без явного подтверждения пользователя.

## Сборка
Откройте проект в Android Studio или выполните:

```bash
gradle :app:assembleDebug
```

GitHub Actions собирает APK при push в основную ветку. Подписанные релизы публикуются в GitHub Releases.
