# История изменений

## 2.5 — ИИ-фотограф (в разработке)
- Добавлен локальный анализ фотографий встроенной моделью Google ML Kit Image Labeling.
- Добавлено кэширование распознанных меток в SQLite.
- Добавлены умные альбомы по съёмочным сериям с русскими названиями на основе распознанных сюжетов.
- Добавлен просмотр виртуальных категорий с количеством снимков; это фильтры внутри приложения, не физические папки.
- События группируются с учётом временной близости и совпадения сюжетов/категорий, а не только даты.
- Снимки по одному или по два не формируют отдельные альбомы.
- Новый режим не перемещает, не переименовывает и не удаляет оригинальные файлы.
- Старое распределение только по календарным датам заменено вкладкой «ИИ-альбомы».
- Сборка и публикация APK ещё ожидают проверки GitHub Actions.
