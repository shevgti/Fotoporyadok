# История изменений

## 2.10 — обновления, возврат назад и касание фотографий
- Проверка новой версии запускается сразу при каждом возвращении ФотоПорядка на передний план; пока приложение открыто, дополнительная проверка остаётся каждые 30 минут.
- Системная кнопка «Назад» и жест от края экрана обрабатываются единым обработчиком: из фотографий возвращают в альбом/категорию, из альбома — к списку ИИ-альбомов, затем на главный экран.
- Убрано отдельное диалоговое окно предпросмотра фото в ИИ-альбомах и категориях.
- При удержании пальца фотография плавно увеличивается прямо в сетке, после отпускания возвращается к обычному размеру.

## 2.8 — события, видеопревью и упрощение настроек
- ИИ-альбомы группируют фотографии в пределах одного календарного дня и съёмочной сессии; смена сюжета с людей на еду, животных или природу сама по себе больше не разрывает одно событие.
- Названия событий выбираются по общему контексту серии: например, «Шашлыки и отдых», «Встреча на природе», «Пикник на природе»; категория «Природа и путешествия» разделена, обычные природные снимки больше не называются путешествиями.
- Люди имеют приоритет над случайными метками животных при выборе категории фотографии.
- На главной странице для видео извлекается реальный кадр из файла (примерно на первой секунде) в фоновом потоке; серый блок с надписью «ВИДЕО» заменён миниатюрой с отметкой воспроизведения.
- Пункт и отдельный экран «Центр уведомлений» удалены из настроек. Системные уведомления об обновлениях и разрешение на уведомления сохранены.
- Сохранены исправления прокрутки экрана ИИ-альбомов и системного возврата из версии 2.7.

## 2.7 — исправление прокрутки и возврата в ИИ-альбомах
- Экран ИИ-альбомов теперь занимает ограниченную доступную высоту; списки фотографий прокручиваются внутри своей области и не перекрывают нижние элементы интерфейса.
- Кнопка «Назад» внутри категории/альбома возвращает к списку ИИ-альбомов.
- Системная кнопка и жест Android «Назад» сначала закрывают открытую категорию/альбом; следующий возврат ведёт на главный экран, не сворачивая приложение.
- На экране ИИ-альбомов Back обрабатывается одним владельцем, чтобы внешний обработчик Activity не перехватывал вложенную навигацию.

## 2.6 — исправления ИИ-альбомов и навигации
- Результаты ИИ-анализа восстанавливаются из локального кэша после перехода на другую вкладку и возврата.
- Обложки альбомов показывают коллаж из 3–4 миниатюр вместо одной вытянутой полосы.
- Убраны категории и сырые ML Kit labels рядом с фотографиями внутри альбомов и категорий.
- Повышен порог уверенности распознавания; одиночная метка животного больше не назначает категорию «Животные».
- Системная кнопка/жест «Назад» возвращает с ИИ-альбомов на главный экран, закрывает боковое меню и полноэкранный просмотр.
- Индикатор обновления показывает текст «Доступно новое обновление» и номер версии.


## 2.5 — ИИ-фотограф (в разработке)
- Добавлен локальный анализ фотографий встроенной моделью Google ML Kit Image Labeling.
- Добавлено кэширование распознанных меток в SQLite.
- Добавлены умные альбомы по съёмочным сериям с русскими названиями на основе распознанных сюжетов.
- Добавлен просмотр виртуальных категорий с количеством снимков; это фильтры внутри приложения, не физические папки.
- События группируются с учётом временной близости и совпадения сюжетов/категорий, а не только даты.
- Снимки по одному или по два не формируют отдельные альбомы.
- Новый режим не перемещает, не переименовывает и не удаляет оригинальные файлы.
- Старое распределение только по календарным датам заменено вкладкой «ИИ-альбомы».
- Сборка и публикация APK ещё ожидают проверки GitHub Actions.


## 2.9 — исправления по последним замечаниям пользователя
- Увеличены расстояния между кнопками «Уведомления» и «Оформление», а также между нижними кнопками меню; добавлены отдельные тени, чтобы контуры не сливались.
- Для ИИ-альбомов улучшено семантическое объединение: одного совпадения по времени/дате недостаточно; учитываются общие сюжетные признаки, устойчивые тематические совпадения и близость съёмки.
- Название события теперь выбирается по доле фотографий с доминирующей темой; специфические уточнения («море», «семейный праздник») требуют подтверждения заметной долей снимков, а не одной случайной меткой.
- Системный Back сначала закрывает увеличенный предпросмотр фотографии, затем возвращает из альбома/категории; следующий Back возвращает на главный экран.
- В альбомах фотографии остаются в сетке 2 колонки с полным отображением кадра; касание открывает увеличенный предпросмотр без полноэкранного перехода.
- Кнопка «Выход» завершает задачу через finishAndRemoveTask(), чтобы убрать приложение из списка недавних.
- versionCode 29 / versionName 2.9. Сборка и публикация APK ожидают GitHub Actions; проверка на Poco F8 Ultra — после установки.
