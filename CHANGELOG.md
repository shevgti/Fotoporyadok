# История изменений

## 2.20 — мгновенное открытие обновления и плавный предпросмотр фото
- Фоновое уведомление теперь передаёт версии приложения данные найденного релиза; при нажатии центральное окно обновления открывается сразу, без ожидания сетевого запроса GitHub.
- Проверка актуальности релиза продолжается в фоне; кнопка «Скачать и установить» доступна сразу из данных уведомления.
- В ИИ-альбомах и категориях удержание фотографии открывает более крупный предпросмотр с плавным увеличением и уменьшением.
- После долгого нажатия предпросмотр остаётся открытым при перемещении пальца по экрану и закрывается после отпускания.
- versionCode 40 / versionName 2.20.

## 2.19 — открытие обновления из уведомления и улучшенный предпросмотр фото
- Нажатие на системное уведомление «Доступно обновление» теперь открывает приложение и сразу показывает центральное окно с действием «Скачать и установить», а не просто переводит на главный экран.
- Если уведомление устарело и обновление уже недоступно, приложение показывает понятное сообщение.
- В предпросмотре фото в ИИ-альбомах/категориях убрана затемняющая подложка вокруг фотографии; область вокруг изображения прозрачная.
- Само фото в предпросмотре увеличено: область отображения до 97% ширины и 70% высоты доступной области; сохранено пропорциональное отображение без обрезки.
- versionCode 39 / versionName 2.19.

## 2.18 — временная ускоренная проверка обновлений
- Для тестирования включён временный интервал проверки обновлений около 2 минут.
- На переднем плане приложение проверяет GitHub примерно каждые 2 минуты вместо 30.
- В фоне стандартная периодическая задача WorkManager (минимум 15 минут) временно заменена цепочкой одноразовых задач с задержкой 2 минуты после каждого запуска.
- В настройках обновлений отображается предупреждение о тестовом режиме.
- После завершения тестирования вернуть `FAST_TEST_MODE = false` в `UpdateCheckWorker.kt`; фон снова перейдёт на обычную периодическую проверку 15 минут, передний план — на 30 минут.
- versionCode 38 / versionName 2.18.

## 2.17 — центрированный предпросмотр фото и диагностика фоновых обновлений
- В ИИ-альбомах и категориях при удержании фотографии вместо растягивания карточки в сетке открывается крупный предпросмотр поверх экрана; изображение центрируется, целиком помещается в область просмотра и закрывается при отпускании пальца.
- Кнопка системного возврата закрывает увеличенный предпросмотр прежде, чем возвращать из альбома/категории.
- Фоновая задача проверки обновлений сохраняет время и результат последнего запуска, включая причины, по которым уведомление не было отправлено; статус отображается в настройках обновлений.
- versionCode 37 / versionName 2.17.

## 2.16 — заметное увеличение фото при удержании
- В основной сетке фотографий удержание пальца увеличивает снимок примерно в 1,65 раза поверх соседних карточек; при отпускании он плавно возвращается к исходному размеру.
- Такое же увеличение при удержании включено для фотографий внутри ИИ-альбомов и категорий.
- versionCode 36 / versionName 2.16.

## 2.15 — компактная шапка и миниатюры ИИ-альбомов
- Заголовок страницы ИИ-альбомов сокращён до «ИИ-альбомы», описание стало однострочным и компактным.
- Кнопка запуска анализа стала ниже и получила короткую подпись.
- В карточке альбома теперь показываются до 8 квадратных миниатюр в 4 колонки вместо 4 крупных вытянутых изображений.
- versionCode 35 / versionName 2.15.

## 2.14 — настройки обновлений и уведомлений
- В настройки добавлен раскрывающийся раздел «Обновления» с выбором: спрашивать перед обновлением или автоматически скачивать новый APK.
- В автоматическом режиме приложение скачивает обновление при обнаружении новой версии, когда приложение открыто; установку APK всё равно подтверждает системный установщик Android.
- Раздел «Уведомления» теперь раскрывает подменю с текущим состоянием и переключателем уведомлений внутри приложения.
- Если системное разрешение Android запрещено, настройки предлагают открыть системный экран уведомлений приложения.
- Фоновая проверка уважает выключенный пользователем переключатель уведомлений.
- versionCode 34 / versionName 2.14.


## 2.13 — компактная страница ИИ и фоновые уведомления об обновлениях
- Верхний блок страницы ИИ сокращён: убран лишний текст, уменьшен заголовок и расстояния, чтобы освободить место для содержимого.
- Фоновая проверка обновлений запускается вскоре после открытия приложения и повторяется с минимальным поддерживаемым Android интервалом WorkManager — 15 минут (системой может выполняться позже).
- Старое расписание проверки раз в 12 часов автоматически обновляется.
- Уведомление не считается отправленным, если Android не принял его; используется общий идентификатор уведомления, чтобы не создавать дубликаты.
- Исправлена загрузка обновлений: прогресс, проверка полученного APK и видимое сообщение об ошибке.
- versionCode 33 / versionName 2.13.

## 2.12 — проверка и исправление возврата из ИИ-альбомов
- Уточнена тестовая подготовка: ожидание главного экрана опирается на фактическую загрузку трёх тестовых фото, а не на необязательную надпись в шапке.
- Добавлены Android UI regression tests для кнопки «Назад», системной кнопки Back, жеста от края экрана и возврата из категории; тесты используют локальный кэш и не зависят от ML распознавания.
- versionCode 32 / versionName 2.12. Проверка на Poco F8 Ultra ожидает установки APK пользователем.

## 2.11 — исправление возврата из ИИ-альбомов
- Вложенный экран ИИ-альбомов самостоятельно обрабатывает системную кнопку «Назад» и жест Android: сначала закрывает открытую категорию или альбом, затем возвращает на главный экран.
- Кнопка «Назад» внутри категории и альбома использует тот же обработчик, что и системная навигация.
- Убрана передача обработчика возврата через состояние родительского экрана, из-за которой Activity могла перехватить Back раньше вложенной навигации.
- versionCode 31 / versionName 2.11.

## 2.10 — обновления, возврат назад и касание фотографий
- Проверка новой версии запускается сразу при каждом возвращении ФотоПорядка на передний план; пока приложение открыто, дополнительная проверка остаётся каждые 30 минут.
- Системная кнопка «Назад» и жест от края экрана обрабатываются единым обработчиком: из фотографий возвращают в альбом/категорию, из альбома — к списку ИИ-альбомов, затем на главный экран.
- Убрано отдельное диалоговое окно предпросмотра фото в ИИ-альбомах и категориях.
- При удержании пальца фотография плавно увеличивается прямо в сетке, после отпускания возвращается к обычному размеру.

## 2.8 — события, видеопревью и упрощение настроек
- ИИ-альбомы группируют фотографии в пределах одного календарного дня и съёмочной сессии; смена сюжета с людей на еду, животных или природу сама по себе больше не разрывает одно событие.
- Названия событий выбираются по общему контексту серии: например, «Шашлыки и отдых», «Встреча на природе», «Пикник на природе»; категория «Природа и путешествия» разделена, обычные природные снимки больше не называются путешествиями.
- Люди имеют приоритет над случайными метками животных при выборе категории фотографии.
- На главной странице для видео извлекается реальный кадр из файла (примерно на первой секунде) в фоновом потоке; серый блок с надписью «ВИДЕО» заменён миниатюрой с отметкой воспроизведения.
- Пункт и отдельный экран «Центр уведомлений» удалены из настроек. Системные уведомления об обновлениях и разрешение на уведомления сохранены.
- Сохранены исправления прокрутки экрана ИИ-альбомов и системного возврата из версии 2.7.

## 2.7 — исправление прокрутки и возврата в ИИ-альбомах
- Экран ИИ-альбомов теперь занимает ограниченную доступную высоту; списки фотографий прокручиваются внутри своей области и не перекрывают нижние элементы интерфейса.
- Кнопка «Назад» внутри категории/альбома возвращает к списку ИИ-альбомов.
- Системная кнопка и жест Android «Назад» сначала закрывают открытую категорию/альбом; следующий возврат ведёт на главный экран, не сворачивая приложение.
- На экране ИИ-альбомов Back обрабатывается одним владельцем, чтобы внешний обработчик Activity не перехватывал вложенную навигацию.

## 2.6 — исправления ИИ-альбомов и навигации
- Результаты ИИ-анализа восстанавливаются из локального кэша после перехода на другую вкладку и возврата.
- Обложки альбомов показывают коллаж из 3–4 миниатюр вместо одной вытянутой полосы.
- Убраны категории и сырые ML Kit labels рядом с фотографиями внутри альбомов и категорий.
- Повышен порог уверенности распознавания; одиночная метка животного больше не назначает категорию «Животные».
- Системная кнопка/жест «Назад» возвращает с ИИ-альбомов на главный экран, закрывает боковое меню и полноэкранный просмотр.
- Индикатор обновления показывает текст «Доступно новое обновление» и номер версии.


## 2.5 — ИИ-фотограф (в разработке)
- Добавлен локальный анализ фотографий встроенной моделью Google ML Kit Image Labeling.
- Добавлено кэширование распознанных меток в SQLite.
- Добавлены умные альбомы по съёмочным сериям с русскими названиями на основе распознанных сюжетов.
- Добавлен просмотр виртуальных категорий с количеством снимков; это фильтры внутри приложения, не физические папки.
- События группируются с учётом временной близости и совпадения сюжетов/категорий, а не только даты.
- Снимки по одному или по два не формируют отдельные альбомы.
- Новый режим не перемещает, не переименовывает и не удаляет оригинальные файлы.
- Старое распределение только по календарным датам заменено вкладкой «ИИ-альбомы».
- Сборка и публикация APK ещё ожидают проверки GitHub Actions.


## 2.9 — исправления по последним замечаниям пользователя
- Увеличены расстояния между кнопками «Уведомления» и «Оформление», а также между нижними кнопками меню; добавлены отдельные тени, чтобы контуры не сливались.
- Для ИИ-альбомов улучшено семантическое объединение: одного совпадения по времени/дате недостаточно; учитываются общие сюжетные признаки, устойчивые тематические совпадения и близость съёмки.
- Название события теперь выбирается по доле фотографий с доминирующей темой; специфические уточнения («море», «семейный праздник») требуют подтверждения заметной долей снимков, а не одной случайной меткой.
- Системный Back сначала закрывает увеличенный предпросмотр фотографии, затем возвращает из альбома/категории; следующий Back возвращает на главный экран.
- В альбомах фотографии остаются в сетке 2 колонки с полным отображением кадра; касание открывает увеличенный предпросмотр без полноэкранного перехода.
- Кнопка «Выход» завершает задачу через finishAndRemoveTask(), чтобы убрать приложение из списка недавних.
- versionCode 29 / versionName 2.9. Сборка и публикация APK ожидают GitHub Actions; проверка на Poco F8 Ultra — после установки.
