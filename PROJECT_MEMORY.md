# Память проекта ФотоПорядок

Этот файл — главная точка входа для продолжения работы в новом чате. Перед изменением кода прочитать его, README.md, TASKS.md и последние записи CHANGELOG.md.

## Проект
- Репозиторий: https://github.com/shevgti/Fotoporyadok
- Основная ветка: `main`
- Android package: `ru.shev.photoorder`
- Язык интерфейса: русский.
- Устройство для пользовательской проверки: Poco F8 Ultra, Android 16 / HyperOS.
- Сборка: GitHub Actions, workflow `.github/workflows/build.yml`.
- Подписанный APK публикуется в GitHub Releases как `app-release.apk`.

## Правила работы
1. Перед началом новой задачи проверить этот файл, `TASKS.md`, `DECISIONS.md`, `CHANGELOG.md`, README и текущий статус GitHub Actions.
2. Не считать задачу готовой только потому, что код записан. Нужны успешная сборка и опубликованный APK; реальная проверка на телефоне отмечается отдельно.
3. Не удалять и не перестраивать существующие функции без согласования: медиатека, альбомы, поиск, сортировка, полноэкранный просмотр фото/видео, темы, умная сортировка, центр уведомлений и обновление APK.
4. Не перемещать/удалять пользовательские медиа автоматически. Для сортировки обязательно подтверждение.
5. После каждого значимого изменения обновлять `TASKS.md`, `CHANGELOG.md`, при необходимости `DECISIONS.md` и этот файл. В README держать краткий обзор и ссылку сюда.
6. Сохранять важные изображения и макеты в `docs/design/` с понятными именами. Не заменять макет выдуманным вариантом; если исходный макет не найден — запросить его повторно.
7. Пользователю давать короткие и понятные инструкции на русском, писать точные названия кнопок и экранов.

## Проверка обновлений
Приложение проверяет GitHub Releases API `/releases/latest`, читает `tag_name`, `versionCode` из описания и ищет asset `app-release.apk`. Новая версия показывается только если versionCode релиза больше установленного. Периодическая проверка сейчас выполняется, пока процесс приложения активен, раз в 30 минут; это не гарантирует уведомление, когда приложение полностью закрыто/система выгрузила его. Для этого позже потребуется WorkManager и корректные ограничения Android/HyperOS.
