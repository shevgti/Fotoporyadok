# Принятые решения ФотоПорядка

## Интерфейс
- Язык интерфейса — русский.
- Сохранять левое выдвижное меню, открываемое нажатием на значок ФотоПорядка в шапке.
- Пользователю понравился второй из предложенных макетов: более насыщенный, выразительный, объёмный интерфейс вместо бледного плоского оформления. Точную картинку необходимо хранить в `docs/design/`; если её нет, не угадывать и попросить повторно.
- Для кнопок выбран третий вариант — лёгкий диагональный скос.
- Нижняя часть меню: версия приложения и отдельные действия «Обновление», «О приложении», «Выход».
- Кнопка обновления показывает текущую версию; при наличии более новой версии должна заметно выделяться и сообщать номер новой версии.

## Поведение
- «О приложении» открывает сведения о приложении и версии.
- «Выход» требует подтверждения; случайное нажатие не закрывает приложение.
- Проверка обновления сравнивает versionCode, скачивание идёт только с официального GitHub Release.
- Перемещение медиа в умной сортировке выполняется только после явного подтверждения пользователя.
- Оригиналы фото/видео остаются локально на устройстве; не загружать их в интернет.

## Сохранность проекта
- README — краткая документация и входная точка.
- PROJECT_MEMORY — постоянный контекст для новых чатов.
- TASKS — текущие и будущие задачи с чекбоксами.
- CHANGELOG — история релизов и существенных изменений.
- DECISIONS — неизменяемые продуктовые решения и выбранные варианты.
- Макеты и изображения сохранять в docs/design с описанием и источником.
